# Kids Book AI App - Background Music (BGM) Library Guide

## Purpose

This library is designed for AI-generated:

* Story Books
* Nursery Rhymes
* Learning Videos
* Bedtime Stories
* Moral Stories
* Adventure Stories
* Animated Picture Books

Recommended approach:

* Voice-over Volume: 100%
* BGM Volume: 10-20%
* Ducking Enabled (Reduce BGM when narration speaks)
* Loop BGM if story duration exceeds track duration

# AI Story Engine Mapping

Recommended automatic mapping:

Happy Story → happy/

Bedtime Story → bedtime/

Princess Story → magical/

Jungle Story → adventure/

Funny Animal Story → funny/

Educational Content → educational/

Moral Story → emotional/

This mapping can be automatically performed by your LLM before generating the final video.

This version is structured so it can directly become part of your AI kids-book app documentation or be committed into Git as `docs/kids_book_bgm_library.md`.
